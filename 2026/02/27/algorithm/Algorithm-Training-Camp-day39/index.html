题目答案及分析

121. 买卖股票的最佳时机

这道题首先先提一下 非dp 的方案(贪心)
即找到 小和大的 最大差值

而使用动态规划的方法：

  • 下标含义：
    • dp[i][0]: 在第 i 天时，持有股票的 剩余现金
    • dp[i][1]: 在第 i 天时，不持有股票 剩余现金
  • 递归方式：
    • dp[i][0] = max(dp[i - 1][0], 0 - price[i])

      两种来源：

      • 原来 持有 股票，那就 继续持有
      • 直接买入（因为是只能持有一股，那就相当于直接重新买
    • dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + price[i])

      两种来源：

      • 原来 持有 股票，那就 卖掉
      • 原来 不持有 股票，那就 保持
  • 初始化：
    • dp[0][0] = -prices[0]: 第一天持有，就是花费掉
    • dp[0][1] = 0: 第一天不持有，就是保持 0 块钱
  • 迭代顺序：从前往后

122. 买卖股票的最佳时机 II

非 dp 方式

dp方式：
这道题与前一题的差距，在于可以多次买入卖出，那唯一的区别就在于dp[i][0]的迭代更新的第二条途径，改成了从 dp[i - 1][1] - prices;

123. 买卖股票的最佳时机 III

动态规划：

  • 下标含义：
    • dp[i][0]: 在第 i 天时，持有 第一支 股票的 剩余现金
    • dp[i][1]: 在第 i 天时，不持有 第一支 股票 剩余现金
    • dp[i][2]: 在第 i 天时，持有 第二支 股票 剩余现金
    • dp[i][3]: 在第 i 天时，不持有 第二支 股票 剩余现金
  • 递归方式：
    • dp[i][0] = max(dp[i - 1][0], 0 - price[i])

      两种来源：

      • 原来 持有 第一支 股票，那就 继续持有
      • 直接买入（因为 对于第一股 只能持有一股，那就相当于直接重新买
    • dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + price[i])

      两种来源：

      • 原来 持有 第一支 股票，那就 卖掉
      • 原来 不持有 第一支 股票，那就 保持
    • dp[i][2] = max(dp[i - 1][2], dp[i - 1][1] - price[i])

      两种来源：

      • 原来 持有 第二支 股票，那就 继续持有
      • 第二支股票的买入，一定是在 第一支股票卖出之后（即不持有。因为买卖第一支股票后，钱肯定 高于 初始值 0，否则就是不交易）这个时候，在 dp[i - 1][1] 的基础上买入，就是 第二支 股票
    • dp[i][3] = max(dp[i - 1][3], dp[i - 1][2] + price[i])

      两种来源：

      • 原来 持有 第二支 股票，那就 卖掉
      • 原来 不持有 第二支 股票，那就 保持
  • 初始化：
    • dp[0][0] = -prices[0]: 第一天持有，就是花费掉 prices[0]
    • dp[0][1] = 0: 第一天不持有，就是保持 0 块钱
    • dp[0][2] = -prices[0]: 假设之前已经有买卖第一支股票，那么第一天持有 第二支，就是花费掉 prices[0]
    • dp[0][3] = 0: 第一天不持有，就是保持 0 块钱
  • 迭代顺序：从前往后
