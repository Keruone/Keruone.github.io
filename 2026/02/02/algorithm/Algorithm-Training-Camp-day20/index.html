701. 二叉搜索树中的插入操作

这题其实很简单，由于二叉搜索树的特性，所以你只要移动到最底层，然后插入即可。因为二叉搜索树特性，会使得，只要你从上往下的方式符合，最后只要判断放到叶子节点的左侧或者右侧即可

450. 删除二叉搜索树中的节点

我的初版思路

对于找到的目标节点cur：

  • 如果 cur->left == NULL && cur->right == NULL：
    • 说明该节点是叶子节点，可以直接删除
  • 否则 如果 cur->right != NULL：
    • 说明至少有节点存在
    • 那么将原来指向 cur 的指针，指向 cur->right
    • 不需要考虑 cur->left 是否存在，通通添加到 cur->right 的最左侧叶子节点下面
      • 因为无论 cur->left 是 NULL 还是有内容，都满足的
  • 否则，判断到这里说明 cur->left 存在，但是 cur->right 不存在
    • 此时直接拼接即可

卡个思路

以上我的代码其实还是比较冗余，这里我觉得卡哥的 递归思路 非常简单高效。
卡哥的思路中：

  • 将函数视为 返回处理后子树的 root 节点
  • 如果 当前 root 是 NULL ，说明到了叶子节点
    • 此时表示未搜寻到应该删除的节点，本来的子树长什么样子，就一点一点拼回去即可
    • return 本身
  • 如果 当前 root 是我们的 key
    • 这里我替换为了我的判断思路
    • 不过返回值的想法 使用了卡哥的想法。即返回处理后子树的根节点
  • 如果 以上都不满足，就要更深一步的搜寻：
    • 如果 root->val > key，说明当前树的左子树需要修改，需要拼接上修改后的树
      • root->left = deleteNode(root->left, key);
    • 如果 root->val < key，说明当前树的右子树需要修改，需要拼接上修改后的树
      • root->right = deleteNode(root->right, key);
