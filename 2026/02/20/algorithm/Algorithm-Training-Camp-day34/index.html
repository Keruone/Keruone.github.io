卡码网：46. 携带研究材料 二维解法

这道题是 卡哥 思路里的题目：

五部曲内容 对应解析
DP 数组下标含义 i: 0i 下标对应的所有物品; j: 当前允许的空间; dp[i][j]: 在空间为 j 的限制下，物品 0i 组合所允许的最大价值
递推公式 dp[i][j] =
 如果空间j塞得下第i个物品:
  max(当前物品价值+不包含当前物品时剩余空间允许的最大价值, 当前空间在i-1个物品时的最大价值)
 如果当前空间j塞不下第i个物品
  在空间j下，物品为i - 1时候的最大价值
因为剩余空间
初始化 空间为 j = 0 时，初始化 dp数组 为 0
物品第一行(索引为0)，对所有空间允许的 dp数组 初始化为 物品0 的价值
遍历顺序 从前往后

卡码网：46. 携带研究材料 一维解法

基本思路是一致的。不过你可以发现，对于每次赋值时候，用到的都不过是上一行的数组

不过这里在一行中的处理思路需要转变，本来是从前往后处理，但是这样，会出问题：如果放得下当前物品，我们会计算空间差值，考虑剩余空间的价值。但是从前往后遍历时，你会发现后面使用的数值，可能会用到前面的数值。这个时候，我们就会由于使用的数值是覆盖后的数值导致计算错误。
对此，我们应该大循环保持从前往后，小循环保持从后往前。

416. 分割等和子集

这道题用动态规划的背包问题的思路就比较相似了。直接使用 滚动数组压缩后的一维解法。

五部曲内容 对应解析
DP 数组下标含义 j: 表示当前背包的空间j，dp[j]表示在空间j中的最大数值和
递推公式 dp[j] = max(dp[j], dp[j - nums[i]] + nums[i]);
初始化 dp数组全部初始化为0
遍历顺序 大循环(nums[i]遍历)从前往后，小循环(背包内遍历)从后往前
