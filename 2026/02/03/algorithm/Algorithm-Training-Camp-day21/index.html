669. 修剪二叉搜索树

这题实话说其实不是特别好想，不是很有思路。

递归

对于递归的思路，你先要确认你的返回值到底该是什么

  • 此处 应该考虑为：你的返回值，是可以拼接到某一棵现成的树上的，即可以作为子树。所以返回的应该是 子树的根节点

那么据此，我们其实要做的就很简单了：

  • 对于每一个节点，我们先判断节点本身是否满足条件
    • 如果满足条件，那我们就要开始修建它的子树
      • 将它的左子树，塞入修建函数，再用返回值赋值
      • 右子树同理
    • 如果不满足条件
      • 若是当前 val 小于 low，那么说明当前节点，以及当前节点的左子树都是不需要的
        • 考虑到前文已经提及：返回的是子树的根节点，所以那我们就返回 该节点修剪后的右子树（这样相当于直接跳过了当前节点及其左子树）

          说白了，就是如果当前节点不满足，那就将当前节点的右节点拼接到原来位置，再尝试

      • 若是当前 val 大于 high，那么说明当前节点，以及当前节点的右子树都是不需要的
        • 考虑到前文已经提及：返回的是子树的根节点，所以那我们就返回 该节点修剪后的左子树（这样相当于直接跳过了当前节点及其右子树）

          说白了，就是如果当前节点不满足，那就将当前节点的左节点拼接到原来位置，再尝试

迭代

主要是以下步骤：

  1. 为了防止根节点是在范围之外，所以我们需要先移动起始的根节点，使得其处在满足条件的最高处
    • 由于初始根节点在对顶上，如果 root 不在范围内，那么它的左侧或者右侧肯定都不在范围内
    • 如果 val < low，那么向 right 移动， 如果 val > high 那么向 left 移动
    • 每次移动后，root仍然是最顶端的满足区间的节点
    • 每次移动后，满足区间的节点肯定在它下面
  2. 处理 左子树
    • 在根节点移动后，循环处理左子树
    • 由于不像递归可以使用返回值拼接，所以判断等操作时，用的得是父节点
    • 记录当前节点 为 curr
    • 判断 curr->left->val 是否小于 low（得先确认 curr->left 非空）
      • 如果小于，那么将 curr替换为右子树
        • curr->left = curr->left->right;
      • 如果大于等于，那么 curr = curr->left，继续迭代
    • 什么时候发现 curr->left 为空，则退出迭代
  3. 处理 右子树
    • 与 处理左子树 同理

108.将有序数组转换为二叉搜索树

递归

这题起始思路很简单，每次取中值作为当前根节点，然后用左边数组做左子树，右边数组做右子树。
这么一句话分析完，递归思路就出来了，唯一要注意一点的就是区间范围了：

  1. 我区间统一使用 左闭右开
  2. 初始区间范围 left_limit = 0; right_limit = nums.size();
  3. root_idx = left_limit + (right_limit - left_limit) / 2; 这里是为了防止溢出
  4. 接着，就有了两个新的区间
    • 左子树区间 [left_limit : root_idx)
    • 右子树区间 [root_idx + 1 : right_limit)
  5. 在每个区间里迭代即可

迭代

大题思路其实同上，但是这里我们要注意：

  1. 遍历的顺序：观察递归思路，其实遍历的顺序是中左右，即中序遍历
  2. 但与寻常中序遍历不同的是，这里我们还要创建节点之间的连接关系
    • 那此时，我们就还需要在处理当前节点时，新建并连接左右两个节点
      • 判断条件就是当前节点所以是否有超出边界范围
  3. 除了寻常的维护节点之外，我们还要维护左右边界
    • 对此，我们需要除了维护节点的容器之外，还需要同样的容器维护左边界和右边界
