64bit 常数 RV64装入

  • 如果 0 很多，可以 slli 移位
  • 如果本身很抽象复杂，risc 使用 从 内存中取值的方式
    • 用 访问数据的延迟 换取 更短的指令
    • 因为 对于 乱序 cpu，取指令代价 > 取数据代价
      • 指令不到位后续做不了，数据不到位可以先让不用数据的指令先行。

  • 实际的分配策略: 所有变量先分配在M, 需要访问时读入R

程序的内存布局

变量位置

  • 静态数据区 data
    • 不会动态变化，编译时确定
  • 静态数据区 bss
    • 会动态变化，放置的都是未初始化的全局/静态变量
  • 堆区 heap
  • 非静态局部变量，栈区 stack

部分 含义
.set 汇编伪指令，作用是”给一个符号赋值”
.LANCHOR0 符号名（. 开头表示局部符号，不导出到链接器）
. 当前位置计数器（location counter），代表”此刻汇编到哪了”，即当前地址
+ 0 偏移 0，就是当前地址本身

RV32 64 bit 加法


a1a0 组成 64bit，a3a2 组成64bit

  • 先将 a5 赋值为 a0
  • 然后计算 a0+a2 结果，存到 a0
  • a0 与 a5 判断大小决定进位
  • a1 = a1+a3+carry

if-else

所以可以化简为 0 <= x-300 <= 550
所以可以化简为一条跳转指令
