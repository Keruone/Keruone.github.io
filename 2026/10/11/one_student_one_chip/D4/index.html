修改 npc/trm.c

~/ysyx-workbench/abstract-machine/am/src/riscv/npc/trm.c
在 halt 的死循环前添加
asm volatile("mv a0, %0; ebreak" : : "r"(code) : "a0");
其中

部分 含义
asm 嵌入汇编代码
volatile 防止编译器因为认为汇编无用而删除它
mv a0, %0 将第一个操作数的值写入 a0
ebreak 执行 RISC-V 断点指令
第一个 : 后为空 没有输出操作数
"r"(code) 输入操作数，要求编译器将 code 放入通用寄存器
"a0" 告诉编译器这段汇编会修改 a0 寄存器
传递给 npc 的 bin 文件，包含 trm.c 的编译后内容。
而在其中，需要手动添加一条 ebreak

[!tip]
halt() 在执行 ebreak 前通过 mv 将退出码明确写入 a0，确保 NPC 能正确判断 GOOD/BAD TRAP，而不依赖编译器对寄存器的分配。
