Installing Tools

  • sed: Stream Editor, Linux 流编辑器，常用于文本查找、替换、编辑
  • -i : in-place 原地操作
  • s/原内容/新内容/g:
      • s = substitute（替换）
    • archive.ubuntu.com：要被替换的旧域名（Ubuntu 官方源）
    • mirrors.tuna.tsinghua.edu.cn：替换后的新域名（清华镜像站）
    • g = global：整行全局替换（一行里多个匹配项全部替换，不加 g 只替换每行第一个）
  • /etc/apt/sources.list Ubuntu 系统软件源配置文件，apt 下载软件时会读取这里的地址。

cat concatenate 的 缩写，本意是连接、拼接

dpkg Debian package, -i install

1. build-essential

编译工具合集，Ubuntu/Debian 下编译 C/C++ 程序的基础依赖包组。

包含：gcc（C 编译器）、g++（C++ 编译器）、make（工程构建工具）、链接器、基础库、编译辅助工具等。

用途：源码编译软件、开发 C/C++ 程序必备。

2. man

Linux 官方帮助手册。

用法：man 命令名（如 man ls、man gcc），查看命令、函数、配置文件的官方文档。

3. gcc-doc

GCC 编译器的官方文档。

专门存放 gcc 编译器的说明、用法、参数、语法手册，搭配 man 或文档查看器使用。

4. gdb

GNU 调试器，主流的 C/C++ 程序调试工具。

可以断点调试、查看变量、分析程序崩溃、追踪代码执行流程，排查代码 BUG 必备。

5. git

分布式版本控制系统。

用于代码管理、版本回溯、多人协作开发，日常拉取源码、提交代码、管理项目版本。

6. libreadline-dev

readline 库开发版（带头文件、静态库）。

readline 负责命令行的历史记录、方向键编辑、自动补全；-dev 后缀代表开发库，编译依赖该库的程序时必须安装。

7. libsdl2-dev

SDL2 多媒体开发库（开发版）。

SDL2 是跨平台多媒体库，常用于游戏、音视频、图形界面开发，支持窗口、图像、声音、输入设备等功能；-dev 版本用于编译依赖 SDL2 的源码 / 项目。

Vim

DO NOT TRY TO MEMORIZE, LEARN BY USAGE

  • hjkl left down upper right

  • x delete the unwanted character

  • i 添加在 光标位置

  • a 添加到 当前光标 后面

  • A 添加到 当前行 后面

  • d 删除

    • dw until the start of the next word, EXCLUDING its first character.
    • de to the end of the current word, INCLUDING the last character.
    • d$ to the end of the lind, INCLUDING the last character.
    • dd to delete the whole line.

  • w move the cursor to the start of the word

  • e move the cursor to the end of the word

  • Typing a number before motion repeats it that many times.

    • 2w
    • 3e
    • 0 move to the start of the line.

  • operator [number] motion

    • d number motion, like d2w

  • u undo the last command executed (INCLUDING U).

  • U return the line to its original state.

  • ctrl-R redo

  • You need to know that dd will store the line you delete in Vim register.

  • And then, you type p , will put the line below the cursor.

    if you delete a word, like dw de, then you type p will put behind your cursor.
    I guess its because dd contain a 换行 in deleting.

  • r*: The asterisk stands for any characters.

    • Using this command to replace the character under the cursor.
    • After typing r, Vim waits for you to enter a new character.

  • ce: c stands for change, and e move the cursor to the end of the word.

    • It removes all characters from your current position of cursor to the end of the word.
    • After execution, Vim enters insert mode immediately, so you can type new content right away.
    • cw ce c$ cc 同理 d*，分别表示 修改到单词开头/单词结尾/行末/ 修改整行

  • ctrl-G: show your location in the file and the file status

    • "/tmp/tutor1lqf7e" [Modified] line 491 of 965 --50%-- col 1

  • G move to the bottom of the file.

  • gg move to the top of the file.

  • line_number G 跳转到 指定行号

  • /words_you_want_to_search: 从光标位置向下，帮你搜索单词或短语

  • ?words_you_want_to_search：从光标位置向上，帮你搜索单词或短语

    • n 向指定方向寻找下一个，N 向反方向寻找下一个
    • ctrl-O 跳转回上一个光标位置
    • ctrl-I 跳转回下一个光标位置

  • % 匹配括号搜索

    • 在当前位置是 括号的情况下，可以跳转到对应括号的另一半
    • () [] {} 都支持

  • :s/old/new/g 替换当前行 old 内容替换为 new 的内容

    • :s/old/new 仅替换第一个出现的
    • :s/old/new/g 替换当前行全部的
    • :s/old/new/gc 一个一个询问
      • y: yes
      • n: no
      • a: all
      • q: quit
      • l: last
      • ^E（^ 表示 ctrl） 表示向上滚动，但仍保留询问【让你更好观察 context】
      • ^Y（^ 表示 ctrl） 表示向下滚动，但仍保留询问【让你更好观察 context】
    • :#,#s/old/new/g 输入行号范围，批量替换（没有g的话，就替换每行第一个）
    • :%s/old/new/g 全文替换
    • :%s/old/new/gc 全文替换，但是逐个询问

  • :!command 可以让你不出 vim 执行外部终端指令，甚至可以带 参数

    • 这里的 command 指的是 bash 终端中可以执行的指令
    • 注意，指令执行完后会询问你 enter 或 输入 command 继续，这里的 command 指的是 vim 的指令

  • :w file_name 保存到指定文件

    • 然后你甚至可以 :!rm file_name

  • :r TEST 读取并插入

    • 用命令 :r TEST 读取你的 TEST 文件，这里的 TEST 是你自己创建的文件名。读取的文件内容会被插入到光标所在行的下方。
    • 你还可以读取外部命令的输出。例如，:r !ls 会读取 ls 命令的输出结果，并把它插入到光标下方。

  • o 在当前光标下方，开启一个新行，并进入 insert mode

  • O 在当前光标上方，开启一个新行，并进入 insert mode

  • a 在当前位置之后，进入 insert，而 i 是当前位置立马进入 insert

  • A 直接跳转行末，然后进入 insert

  • R 多个替换（其实相当于 windows 常常无处的 insert 模式）

  • v 进入 visual 模式，这个时候光标移动会有选中效果。然后按下 y (yank) 可以复制，然后 p(put)

    其实这个时候回头看， d 反倒有点像 剪切 了

  • yy copy 一整行

  • yw ye 同理

    • 就 自己选择 用 v 进入 visual 模式，别的可以直接 在 normal 模式 靠 w e y 组合直接复制

  • :set ic hls is

    • ic ignore case 不区分大小写
    • hls high light search 高亮搜索
    • is - - 全称：Incremental Search（增量搜索）
      • 作用：在你输入 /ignore 的过程中，Vim 会实时高亮匹配项，边打边跳转到对应的位置，不用等按回车才显示结果。
      • 效果：输入 /ign 时，就会立刻跳到第一个匹配的单词；继续输入 /ignor 会进一步缩小范围，体验更流畅。

  • :help <ENTER> 或者直接 F1 或 HELP 按键，可以直接跳开启帮助界面

  • ![Pasted image 20260528173036.png](Pasted image 20260528173036.png)

  • 此时，连按两次 ctrl-W 可以切换窗口，

  • 同样可以 :q 退出

  • 使用 :help command 可以直接查看 command 的帮助文档

      • 比如输入 :help w，查看普通模式下 w 命令的用法。
    • 比如输入 :help c_CTRL-D，可以查看命令行模式下 Ctrl+D 的补全功能说明。
      • 比如你输入 :set hl，再按 Ctrl+D，Vim 会立刻列出所有以 hl 开头的选项（如 hlsearch、hls 等），帮你快速查看可选值，而不是像 Tab 那样直接补全。
    • 比如输入 :help insert-index，可以查看插入模式下所有快捷键的索引列表。
    • 比如输入 :help user-manual，可以打开完整的 Vim 用户手册。
    • 比如 你可以看到 c_CTRL-D 找到帮助文档。

  • 你可以通过创建 vimrc 文件，来启用很多 vim 多于 vi 的特性

    • :e ~/.vimrc for Unix
    • :e ~/.vimrc for Windows
