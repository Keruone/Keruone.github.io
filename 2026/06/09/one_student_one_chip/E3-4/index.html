命令行环境

任务控制

  • SIGINT signal interrupt, 中断。Ctrl-C 其实就是这个。

  • SIGQUIT signal quit, 停止。Ctrl-\ 其实就是这个。

  • SIGTERM signal terminal, 终止。kell -TERM <PID> 其实就是这个。

  • SIGSTOP signal stop, 暂停。

  • SIGTSTP signal Terminal Stop, 终端暂停。Ctrl-Z 其实就是这个。

  • SIGHUP signal Hang Up, 挂断信号。如终端关闭或推出登陆时，系统向该终端下启动的所有进程（前台和后台）发送 SIGHUP 信号。

  • SIGKILL signal kill，杀死进程。不过注意，有可能留下孤儿进程。

  • fg bg 在 前台/后台恢复暂停的工作（只恢复最近的一个任务）。想恢复全部需要逐个 bg %1 %2 ...。

  • jobs 列出终端中尚未完成的全部任务

  • 也可以使用 pgrep 找出 pid

  • & 后缀，可以让命令在 后台运行

端口转发

通用格式

  • -L = 我求人办事。即 myhost 求 remotehost 办事，动用的是 remotehost 的人脉，联系到了target_host
  • -R = 我为人办事。即 myhost 有人脉联系到 target_host 从而为 remotehost 提供服务。
  • port1 表示的永远是 实际的服务需求方 的入口端口。如:
    • 在 -L 情况下，myhost 是服务需求方，描述的 port1 就是 myhost 上的端口；
    • 在 -R 情况下，remotehost 是服务需求方，描述的 port1 就是 remotehost 上的端口
  • 同理， port2 表示的是 实际服务提供方 的生产端口。

课后练习

习题解答

任务控制

  1. 我们可以使用类似 ps aux | grep 这样的命令来获取任务的 pid ，然后您可以基于 pid 来结束这些进程。但我们其实有更好的方法来做这件事。在终端中执行 sleep 10000 这个任务。然后用 Ctrl-Z 将其切换到后台并使用 bg 来继续运行它。现在，使用 pgrep 来查找 pid 并使用 pkill 结束进程而不需要手动输入 pid。(提示：: 使用 -af 标记)。
  • ps aux 中，ps 表示 process status，a表示全部，u表示用户可读，x表示显示无控制终端的进程（脱离任何终端独立运行的后台进程，用 ?表示）
  • pgrep process grep，
    • -a, --list-full
      List the full command line as well as the process ID. (pgrep only.)
    • -f, --full
      The pattern is normally only matched against the process name. When -f is set, the full command line is used.
  1. 如果您希望某个进程结束后再开始另外一个进程， 应该如何实现呢？在这个练习中，我们使用 sleep 60 & 作为先执行的程序。一种方法是使用 wait 命令。尝试启动这个休眠命令，然后待其结束后再执行 ls 命令。

但是，如果我们在不同的 bash 会话中进行操作，则上述方法就不起作用了。因为 wait 只能对子进程起作用。之前我们没有提过的一个特性是，kill 命令成功退出时其状态码为 0 ，其他状态则是非 0。kill -0 则不会发送信号，但是会在进程不存在时返回一个不为 0 的状态码。请编写一个 bash 函数 pidwait ，它接受一个 pid 作为输入参数，然后一直等待直到该进程结束。您需要使用 sleep 来避免浪费 CPU 性能。

  • wait 可以等待某个后台任务完成，然后终端响应
    *注意：Shell 只在输出提示符之前检查并打印后台作业状态。如果进程结束时你正好在输入命令，状态会延迟到下一个提示符才显示。

终端多路复用

  1. 请完成这个 tmux 教程 参考 这些步骤 来学习如何自定义 tmux。
  • tmux session独立运行在后台进程里，关闭终端只是断开客户端连接，session和其中运行的程序会继续运行。
  • Session（会话）：最外层容器，可以独立分离/重连
  • Window（窗口）：每个 session 可以有多个窗口，类似标签页
  • Pane（窗格）：每个 window 可以被分割成多个 pane
  • 一个 Session 下有 b 个 Window，每个 Window 下有 c 个 Pane，三层结构，互不干扰。

别名

  1. 创建一个 dc 别名，它的功能是当我们错误的将 cd 输入为 dc 时也能正确执行。

  2. 执行 history | awk '{$1="";print substr($0,2)}' | sort | uniq -c | sort -n | tail -n 10 来获取您最常用的十条命令，尝试为它们创建别名。注意：这个命令只在 Bash 中生效，如果您使用 ZSH，使用 history 1 替换 history。

  • 把第一列置空后，awk自动用空格重新拼接所有字段，导致第一个字段（空）和第二个字段之间产生一个多余的空格。
  • substr($0, 2) 的作用是从第2个字符开始截取整行，从而去掉因删除第一列而留下的多余空格，其中 $0 是当前行，数字 2 表示起始位置（跳过第一个字符）。

5. (附加题) 查看 ssh 的 -N 和 -f 选项的作用，找出在后台进行端口转发的命令是什么？

  • -N

    • 不执行远程命令。这仅用于端口转发场景。详见 ssh_config(5) 中 SessionType 的描述。

  • -f

    • 要求 ssh 在命令执行前转入后台。这在 ssh 需要询问密码或密钥口令、但用户希望它在后台运行时很有用。该选项隐含了 -n。在远程站点启动 X11 程序的推荐方式类似于：ssh -f host xterm。
    • 如果 ExitOnForwardFailure 配置选项设置为 “yes”，则以 -f 启动的客户端会在所有远程端口转发成功建立后，才将自身置入后台。详见 ssh_config(5) 中 ForkAfterAuthentication 的描述。

  • -N 就是不执行远端命令，适用于端口转发的情况

  • -f 是让 ssh 在执行命令前切换到后台运行
