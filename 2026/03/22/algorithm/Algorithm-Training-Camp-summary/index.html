历时约两个月，完成了代码随想录算法训练营的学习，共覆盖 60 天（含休息日）、8 大算法专题、100+ 道题目。以下是对整个训练营的系统性回顾。

一、整体学习路线

训练营跳过了若干休息日（Day 5、12、19、26、41、48、55），总计完成 53 天的学习内容。

二、各阶段知识点总结

阶段一：基础数据结构（Day 1–11）

数组（Day 1–2）

  • 核心思想：区间定义的一致性（左闭右闭 vs 左闭右开），双指针，滑动窗口，前缀和
  • 重点题目：
    • 704 二分查找 / 27 移除元素 / 977 有序数组的平方
    • 209 长度最小的子数组（滑动窗口）/ 59 螺旋矩阵 II
    • 卡码网 58 区间和 / 44 开发商购买土地（前缀和）

链表（Day 3–4）

  • 核心思想：虚拟头节点统一边界处理，快慢指针检测环
  • 重点题目：
    • 203 移除链表元素 / 707 设计链表 / 206 反转链表
    • 24 两两交换 / 19 删除倒数第N个 / 142 环形链表 II

哈希表（Day 6–7）

  • 核心思想：用空间换时间，频率统计，配对查找
  • 重点题目：
    • 242 有效字母异位词 / 1 两数之和 / 454 四数相加 II
    • 15 三数之和 / 18 四数之和（双指针 + 去重）

字符串（Day 8–9）

  • 核心思想：原地修改，双指针翻转，字符替换
  • 重点题目：
    • 344 反转字符串 / 541 反转字符串 II / 151 翻转字符串里的单词
    • 卡码网 54 替换数字 / 55 右旋转字符串

栈与队列（Day 10–11）

  • 核心思想：栈的 LIFO 特性处理括号/表达式，单调队列维护区间最值，优先队列（堆）
  • 重点题目：
    • 232 用栈实现队列 / 225 用队列实现栈
    • 20 有效括号 / 150 逆波兰表达式求值
    • 239 滑动窗口最大值（单调队列）/ 347 前K个高频元素（小根堆）

阶段二：二叉树（Day 13–21）

这是训练营中篇幅最长的单一专题，横跨 9 天，涵盖：

遍历方式

  • 前/中/后序遍历（递归、迭代、统一写法）
  • 层序遍历（BFS，衍生出右视图、每层最大值、填充指针等变题）

树的属性与操作

二叉搜索树（BST）

  • 核心：中序遍历有序，充分利用 BST 的值域性质
  • 重点题目：
    • 98 验证 BST / 530 最小绝对差 / 501 众数
    • 235/236 LCA 问题 / 701 插入 / 450 删除 / 669 修剪
    • 108 有序数组转 BST / 538 转累加树

阶段五：动态规划（Day 32–45）

训练营中时间最长的专题（14 天），系统覆盖了 DP 的主要题型。

DP 五部曲：① 定义 dp 含义 → ② 写递推公式 → ③ 初始化 → ④ 确定遍历顺序 → ⑤ 打印验证

  • 完全背包：内层背包正序

  • 求排列数：外层背包，内层物品

阶段六：单调栈（Day 46–47）

核心思想：找左/右第一个更大（或更小）元素时，用单调栈可将暴力 O(n²) 降至 O(n)。

  • 单调递减栈：寻找右边第一个更大元素（739 每日温度 / 496/503 下一个更大元素）
  • 单调递增栈：寻找左右边界求最大面积（84 柱状图最大矩形）
  • 接雨水（42）：单调栈 or 双指针两种经典解法

阶段七：图论（Day 49–60）

训练营最后也是最复杂的专题，全部使用卡码网题目（与 LeetCode 同类型）。

图的遍历

  • DFS / BFS 应用于岛屿问题（计数、面积、沉没孤岛、双源路径）
  • 从边界反向 DFS 标记内部孤岛

并查集

  • 路径压缩 + 按秩合并
  • 应用：684/685 冗余连接（有向/无向图环检测）

最小生成树

  • Prim：适合稠密图，O(n²)
  • Kruskal：适合稀疏图，O(E log E)，基于并查集

最短路径

算法 适用场景 复杂度
Dijkstra（普通） 非负权图 O(n²)
Dijkstra（堆优化） 非负权图 O(E log V)
Bellman-Ford 含负权边 O(VE)
SPFA Bellman-Ford 的队列优化 平均 O(E)
Floyd-Warshall 多源最短路 O(n³)

其他

  • 拓扑排序：入度表 + BFS（课程依赖问题）
  • A* 启发式搜索：f = g + h，曼哈顿距离估价（骑士攻击）

五、个人体会

历时两个月的训练营，从最基础的数组双指针，到图论中的 A* 算法，系统性地走了一遍算法与数据结构的核心地图。

几点深刻感受：

  1. 递归的本质是信任：写树和回溯的递归时，不要试图在脑子里模拟每一层调用，只需定义好函数的语义，相信它能正确返回，专注写好当前层的逻辑。

  2. DP 的难点在于状态定义：推导公式其实是次要的，难在如何定义 dp[i] 或 dp[i][j] 的含义——定义对了，公式自然就出来了。

  3. 贪心没有模板，但有直觉：每道贪心题都需要单独思考和证明，但做多了会慢慢建立起”局部最优能否导出全局最优”的直觉。

  4. 图论是算法的终点，也是新的起点：图论整合了 DFS、BFS、贪心（Prim/Kruskal）、DP（Bellman-Ford/Floyd）、数据结构（并查集、堆）等几乎所有之前学过的内容。

感谢代码随想录的系统编排，让算法学习有了清晰的路径。
