拓扑排序

这主要是处理 一系列事件，但是事件之间有先后关系
比如，只有当 A 做完，才能做 B、 D； B 做完才能做 C、 E；D做完才能做F。

像上图中，A只有出，但没有入，所以可以先做A。
做完A后，将由它产生的输出删去，得到新的一轮可以完成的事件，那么就是 B、D。

那在实现细节上，我结合自己和卡哥的思路，总结如下：

  1. 使用邻接表快速存储，对于每个节点，它的下一级节点
  2. 使用数组记录每个节点 当前 的父节点个数
  3. 使用队列记录将要处理的事件（节点）
  4. 遍历所以数组，找到父节点个数为 0 的，塞入队列
  5. 处理事件时，将该事件从队列中取出，塞入 结果result 中
  6. 当某个事件（节点）处理完毕后，遍历它所对应的邻接表，依次删去所连接节点的父节点个数
  7. 重复 4、5 直到结束

如果 处理完毕后，result 中节点个数 != 输入的节点个数，那就说明有环存在 输出 -1

dijkstra

这主要是找到两点之间的最短路径
处理过程如下：

  1. 根据输入的边，构建邻接矩阵，记录两点之间是否连接以及各自的权重。（注意是有向图还是无向图）
  2. 初始化 minDist 数组，用于记录各个节点到 起始节点的最短路径。初始均为INT_MAX，除了起始节点为0
  3. 初始化 visited 数组，用于记录 节点 是否 处理过
  4. 进入循环：
    1. 遍历寻找 未看过的，并且 minDist 最小的 节点，记作 cur
    2. 将该节点添加为 看过的
    3. 以该节点为出发点，更新所有 未看过的 节点距离，为：min(minDist[j], cur到节点j的距离 + minDist[cur])
